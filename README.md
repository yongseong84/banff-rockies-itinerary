# 밴프 · 재스퍼 로키 2박 3일 동선

캐나다 로키(밴프 국립공원 → 레이크루이스 → 아이스필즈 파크웨이 → 재스퍼)를 렌터카로 도는 **2박 3일 자유여행 동선표**입니다. 캘거리 공항에서 차를 받아 다시 캘거리로 돌아오는 편도형 루트이고, 분 단위 타임테이블과 트레킹 구간까지 붙어 있습니다.

**👉 [동선표 바로 보기](https://yongseong84.github.io/banff-rockies-itinerary/)**

---

## 담고 있는 것

| 구성 | 내용 |
|---|---|
| **출발 전 예약 4가지** | 국립공원 입장권 · Park & Ride 셔틀 · Pursuit Pass · 스테이크하우스 예약 규칙 |
| **D-1 ~ DAY 3 타임테이블** | 모든 정류장의 도착 시각, 체류 시간, 구간별 이동 시간 |
| **트레킹 구간 총정리** | 14개 코스의 구간 · 거리 · 고도 · 소요 시간 · 난이도 |
| **추천 식당** | 실제로 먹은 곳 + 후보였다 뺀 곳과 그 이유 |
| **그 외 추천 코스** | 패스에 있는데 안 쓴 액티비티, +1일 / +2일 / 일주일 확장안 |

## 루트 요약

```
D-1  밴쿠버 ─(WS122, 1h30)→ 캘거리 공항 → 공항 앞 1박
D1   Alamo 렌터카 → H-Mart 장보기 → 투잭 호수 → 미네왕카 크루즈
     → 후두스 → 밴프 애비뉴 → 밴프 곤돌라(일몰) → 밴프 1박
D2   Brazen 브런치 → Park & Ride → 레이크 루이스 → 모레인 호수
     → 크로풋 → 보우 호 → 페이토 호수 → 컬럼비아 아이스필드 → 재스퍼 1박
D3   피라미드 아일랜드 → 재스퍼 타운 → 선왑타 폭포
     → 스터트필드 전망대 → 캘거리 공항 반납 (4h30)
```

- **시즌 기준** 10월 초 비수기 · 일출 07:45 / 일몰 19:00
- **총 운전** 약 12시간 (3일 합산) · **총 도보** 약 8~9 km
- **인원 기준** 4인 가족, Standard SUV

## 시각과 수치의 출처

- **원문에 적힌 값**(소요 시간, 요금, 운영 시간, 예약 규칙)은 그대로 옮겼습니다.
- **원문에 시각이 없는 구간**은 실제 도로 소요 시간과 일출·일몰을 기준으로 역산한 **권장 시각**입니다. 페이지에서 초록색으로 표시됩니다.
- **예약·운영에 묶인 고정 시각**(셔틀, 설상차, 식당 오픈, 체크인)은 노란색으로 구분했습니다.
- **트레킹 거리·고도** 중 원문에 없는 값(레이크 아그네스, 빅 비하이브, Rockpile, 페이토, 설퍼산 보드워크, 레이크루이스 Lakeshore)은 공개된 트레일 정보로 보완했습니다.

> 국립공원 입장 정책, Pursuit Pass 이용 시간 규정, 셔틀 예약 방식, 식당 영업시간은 해마다 바뀝니다. 출발 전 공식 사이트에서 다시 확인하세요.

## 원 출처

모든 여행 정보는 네이버 블로그 **[방구의 여행일기](https://m.blog.naver.com/sk8230)** 의 「2025 캐나다」 카테고리 14편을 바탕으로 이동 순서대로 재구성한 것입니다. 각 정류장마다 해당 원문 링크가 달려 있고, 페이지 하단에 14편 전체 목록이 있습니다.

이 저장소에는 **원문의 사진이 포함되어 있지 않으며**, 본문을 그대로 옮긴 것이 아니라 동선 중심으로 요약·재구성한 자료입니다. 자세한 후기와 사진은 원문에서 보시기 바랍니다.
